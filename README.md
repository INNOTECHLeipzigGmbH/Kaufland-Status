Statusreport der laufenden Kaufland-Projekte von INNOTECH Leipzig GmbH.

- Quelle: `Aufstellung Kaufländer.xlsx`
- Daten zusätzlich gespiegelt in Supabase (Projekt "Protokoll", Tabelle `kaufland_status`)
- `index.html` ist ein eigenständiges Dashboard (keine Build-Schritte nötig) – kann direkt über GitHub Pages veröffentlicht werden (Settings → Pages → Deploy from branch → main / root)
